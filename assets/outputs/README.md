# Experiment Output Figures

Store selected, genuinely generated charts and visualisations in exercise-specific folders, for example:

- `assets/outputs/ex-01/missing-values-heatmap.png`
- `assets/outputs/ex-02/regression-line.png`
- `assets/outputs/ex-09/confusion-matrix.png`

Only add figures generated by running the corresponding experiment. Do not use placeholder or fabricated results. Link figures from the matching exercise README. Jupyter notebooks can also store their own outputs after execution.
