## Dataset paths
The original programs refer to datasets such as `Dataset/titanic.csv`, `Dataset/Salary.csv`, `Dataset/Housing.csv`, `Dataset/fish.csv`, and `heart_disease_dataset.csv`. Place the required dataset files at the paths expected by each script, or update the paths before running.

## Dependencies
Common libraries used across the exercises include pandas, numpy, matplotlib, seaborn, and scikit-learn. Some clustering exercises also use scipy.

The `.md` files preserve text output found in the record. Plots are generated when the scripts are run; their images are not included in these extracted files.
